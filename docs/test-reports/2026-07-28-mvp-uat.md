### 原生保存对话框现场确认与自动化限制

打包 Edge 页面中 `typeof window.showSaveFilePicker === "function"` 为真。进行了最后一次 8 秒有界诊断，并同时通过 UIA 与 Win32 枚举所有新顶层窗口；点击后没有出现可自动控制的新窗口，页面 notice 保持“解析完成，可以下载了。”且 error 为空。

与此同时，用户在本次 packaged UAT 现场确认看到了 Edge 原生“另存为”窗口弹出。因此：

- 已验证打包版“选择保存位置”分支的真实流式响应、WritableStream 写入、文件哈希和 MP4 解码；
- Windows 原生保存窗口出现由用户现场观察验证为 PASS；
- UIA/Win32 自动化未捕获该窗口，是自动化可观测性限制，不是功能失败；
- 路径选择后的字节完整性由受控 packaged-page WritableStream 分支验证。

这里没有把 UIA/Win32 未检测到窗口误写成产品失败，也没有把受控 picker 写成原生窗口自动控制成功。
