# 使用单进程深模块架构

扩展后的应用继续作为一个只监听 `127.0.0.1` 的 Windows 本地进程运行。FastAPI、本地网页、任务调度、SQLite、文件归档、FFmpeg 调用、隔离授权和系统托盘由同一应用进程管理；不拆分独立后端，不嵌入参考项目的整套运行时。

网页路由保持轻薄，只负责本地会话校验、输入输出转换和调用模块接口。快速下载、托管归档、档案库、设置与授权分别形成模块，其中托管归档是主要深模块：其小型接口覆盖预览、确认开始、任务控制和状态查询，来源分页、跨来源去重、三级任务状态、并发重试、磁盘检查、文件完整性和恢复规则隐藏在实现内部。

作者主页和公开视频合集通过统一来源发现接口返回标准化作品快照。访客访问与隔离授权是同一外部接缝上的不同适配器；调用者只能获得能力结果，不能接触 Cookie、令牌或浏览器存储。授权数据不进入任务对象、SQLite 或日志。

归档成果流水线统一负责媒体选择、`.part` 文件、完整性校验、原子改名、封面、元数据、可选音频和文案。档案库只管理长期作品与成果，不依赖某次任务的执行细节。SQLite 和文件系统保持为模块内部接缝，测试通过临时数据库、临时目录和外部访问的测试适配器验证模块接口。

快速下载模块继续保留现有解析令牌与浏览器保存路径，不依赖托管归档任务是否可用。三个规格周期依次建立托管归档基础、公开来源适配器、隔离授权适配器，避免一次性重写现有应用。
