# 多来源批量操作保留来源边界

一次批量操作允许用户添加最多 10 个作者主页或公开视频合集。应用不把这些链接合并成一个无结构输入或不可区分的扫描任务，而是为每个来源保留独立的类型识别、扫描范围、游标、状态、预览、错误、重试和取消边界。用户可以统一确认全部来源，作品层则按作品 ID 跨来源去重；单个来源失败不阻断其他来源。

这样既满足重度用户一次安排多个公开来源的需求，也使授权升级、风险控制、资源估算和故障定位仍能精确到来源。多条单视频链接导入属于另一种批量能力，不纳入首期来源清单。

任务中心统一采用“批量操作 → 来源任务 → 作品任务”三级结构。默认展示批量操作与来源任务汇总，仅在查看详细进度或排查失败时展开作品任务；单来源操作也沿用同一结构，不维护第二套任务模型。

同一作品被多个来源发现时，只为来源清单中最先发现它的来源创建一个作品任务；其他来源保留“跨来源重复”关系。批量操作总数按去重后的作品计算，每个来源分别显示扫描发现数和实际归档数，避免来源汇总与总体进度相互矛盾。

扫描范围采用“统一默认＋逐项覆盖”：来源项默认继承最新 50 个作品，用户可把数量或发布日期区间统一应用到全部来源，也可单独覆盖某个来源；每个来源首期最多扫描 500 个作品。最终生效范围随批量操作保存，后续全局设置变化不追溯修改。

部分来源扫描失败时，成功来源仍可进入预览；失败来源保留原因并允许单独重试、调整授权或移除。失败来源不能显示为零作品，也不会被静默忽略。用户只有明确确认“本次仅包含成功来源”后才能创建批量操作，也可选择暂不开始并先处理全部失败来源。
