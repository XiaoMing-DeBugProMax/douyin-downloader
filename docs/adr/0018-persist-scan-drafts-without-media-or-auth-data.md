# 持久化扫描草稿但不保存媒体或授权数据

来源扫描开始时创建用户可见的扫描草稿，并在 SQLite 中保存来源清单、各来源扫描范围与状态、跨来源发现关系，以及生成预览所需的筛选后作品快照。扫描草稿在应用重启后仍可查看、重试、确认或由用户主动丢弃；首期不自动过期。

扫描草稿不是正式归档操作，确认前不创建作品下载任务，也不写入本地档案库。用户确认后，应用冻结操作设置快照并根据去重和选择结果创建“批量操作 → 来源任务 → 作品任务”结构。

草稿不得保存 Cookie、授权令牌、浏览器存储、短期媒体地址或完整平台响应。确认并开始归档时，作品任务必须重新解析当前远端资源。这样牺牲少量 SQLite 空间，换取多来源长扫描在应用重启后的可恢复性，同时避免让未确认扫描产生媒体下载或扩大敏感数据持久化范围。

每个来源记录最后扫描时间；超过 24 小时后仅标记“结果可能已变化”，不强制失效或删除。用户可刷新全部来源或单独刷新某个来源，刷新后重新计算跨来源去重、档案完整性和空间估算。不刷新直接确认时，操作使用草稿中已选作品，不自动加入后来发布的新作品；作品任务开始下载前仍重新解析远端资源，已删除、转为私密或权限变化的作品按当前状态明确失败。
