# 抖音单视频本地下载器设计规格

- 状态：口头设计已确认，书面规格待审阅
- 日期：2026-07-28
- 风险等级：L1，低风险个人本地工具
- 规格范围：Windows 单机 MVP

## 1. 项目定义

为单个 Windows 用户提供一个仅在本机运行的网站：用户粘贴自己有权下载的抖音公开视频分享文案或链接，网站解析作品信息、展示预览，并将无水印 MP4 下载到浏览器默认目录或用户选择的位置。

### 目标用户

- 仅限本机所有者本人。
- 用户不需要了解 Python、命令行或服务器配置。

### 核心价值

- 将“复制抖音分享内容到获得本地 MP4”缩短为一次粘贴、一次解析和一次下载。
- 不依赖公开第三方解析网站。
- 不读取抖音登录信息，不保存下载历史。

### 最小用户旅程

1. 双击 Windows 启动程序。
2. 小型控制窗口出现，默认浏览器自动打开本地网站。
3. 用户粘贴分享文案或链接并点击“开始解析”。
4. 页面展示封面、作者、文案和时长。
5. 用户点击“下载视频”或“选择保存位置”。
6. MP4 保存到本地；用户可以解析另一个视频或关闭控制窗口退出。

### 成功标准

- 用户无需命令行即可完成完整旅程。
- 给定已验证的公开作品 `7429378937383308594`，连续 3 次人工验收均能得到正确作者、文案、时长和有效 MP4。
- 下载文件可正常播放，且与验证基线 SHA-256
  `B594D1DF250D2450266C1D4714BE9C300FEFFCFEB18E1E6B2928823AEFC02093`
  一致；若抖音重新编码导致哈希变化，则以作品 ID、时长、有效 MP4 结构和人工无水印检查为准。
- 服务只监听回环地址，局域网内其他设备无法访问。

## 2. MVP 范围

### Must

- Windows 双击启动和小型控制窗口。
- 自动打开默认浏览器。
- 接受完整分享文案、`v.douyin.com` 短链接和抖音作品长链接。
- 仅解析单个公开视频。
- 展示封面、作者、文案和时长。
- 默认下载和选择保存位置。
- 明亮、深色、冷静三种主题及本机偏好记忆。
- 中文错误提示、超时处理和一次受控重试。
- 本机限定、安全的 URL 校验、流式下载和最小化日志。

### 明确非目标

- 批量下载、用户主页、喜欢、收藏、合集和图集。
- 直播、私密、付费、受限、删除或需要登录的内容。
- 局域网访问、公网部署、多用户、账号和权限系统。
- 数据库、云存储、下载历史和遥测。
- 自动绕过验证码、登录或平台访问控制。
- 自动更新器、浏览器扩展和移动应用。

## 3. 功能需求与验收条件

### FR-001 启动与控制窗口

**行为**

- EXE 启动 FastAPI 服务时只绑定 `127.0.0.1`，使用可用本地端口。
- 控制窗口显示“服务运行中”、本地地址、“重新打开网页”和“停止并退出”。
- 首次启动成功后自动打开默认浏览器。
- 关闭控制窗口等价于“停止并退出”，服务需要正常释放端口。
- 每次启动生成随机本地会话密钥；控制窗口通过一次性启动链接让浏览器建立
  `HttpOnly`、`SameSite=Strict` 会话 Cookie，随后重定向到不含密钥的干净地址。
- 运行信息写入当前 Windows 用户目录下的
  `%LOCALAPPDATA%\DouyinLocalDownloader\runtime.json`，包含重复启动所需的本地地址、
  实例 ID 和会话恢复信息。
- 再次启动时，如果运行信息指向通过应用健康检查的现有实例，则只打开现有页面并退出第二个进程；失效的运行信息可以安全覆盖。

**验收**

- GIVEN 程序未运行，WHEN 双击 EXE，THEN 控制窗口和网页均出现。
- GIVEN 程序已运行，WHEN 再次双击 EXE，THEN 不产生第二个服务实例并打开已有网页。
- GIVEN 服务正在运行，WHEN 用户关闭控制窗口，THEN 健康检查随后不可访问且端口被释放。

### FR-002 输入识别与校验

**行为**

- 输入长度为 1 至 2000 个字符。
- 从分享文案中提取第一个 HTTP/HTTPS 链接。
- 页面输入只接受以下作品入口主机：
  `douyin.com`、`www.douyin.com`、`v.douyin.com`、
  `iesdouyin.com` 和 `www.iesdouyin.com`。
- 短链接重定向的每一跳都必须重新执行域名与协议校验。
- 最多跟随 5 次重定向。

**验收**

- GIVEN 完整分享文案，WHEN 解析，THEN 提取其中的抖音短链接。
- GIVEN 抖音短链接或作品长链接，WHEN 解析，THEN 得到同一作品 ID。
- GIVEN 空输入、超过 2000 字符、非 HTTP(S) 地址或非抖音域名，WHEN 提交，THEN 返回可读的 400 错误且不发起任意外部请求。

### FR-003 作品解析

**行为**

- 使用自托管 Python 解析适配器；验证基线为 `f2 0.0.1.7` 的
  `DouyinCrawler`、`PostDetail` 和 `PostDetailFilter` 底层接口。
- 不使用会触发 Bark 通知的 `DouyinHandler` 上层流程。
- 解析器只生成游客标识，不读取浏览器 Cookie 或抖音登录状态。
- 返回作品 ID、作者、文案、时长、本地封面代理地址和随机解析令牌。
- 原始媒体地址不返回给前端。
- 解析记录只存在内存中，10 分钟后过期；最多保留最近 20 条记录。

**验收**

- GIVEN 已验证公开作品，WHEN 解析成功，THEN 页面显示作者“钟哥！！”、文案“#王者荣耀 #王者荣耀热门”和时长 15279 毫秒。
- GIVEN 私密、删除、图集、直播或无法访问的作品，WHEN 解析，THEN 返回明确错误，不生成下载令牌。
- GIVEN 解析令牌超过 10 分钟，WHEN 请求预览或下载，THEN 返回 410 并提示重新解析。

### FR-004 解析结果页面

**行为**

- 成功卡片显示封面、作者、文案、格式 MP4、时长以及下载操作。
- 提供“下载视频”“选择保存位置”“解析其他视频”。
- 解析期间按钮显示进度并禁止重复提交。
- “解析其他视频”清空当前页面状态，但不删除已经下载的文件。

**验收**

- GIVEN 解析请求尚未完成，WHEN 用户重复点击，THEN 前端只保留一个活动请求。
- GIVEN 解析成功，WHEN 用户点击“解析其他视频”，THEN 页面回到可输入状态。

### FR-005 默认下载

**行为**

- `GET /api/download/{parse_token}` 从受信任 CDN 流式读取媒体并流式返回。
- 响应使用 `Content-Type: video/mp4` 和安全的 `Content-Disposition: attachment`。
- 建议文件名为“作者 - 文案.mp4”；文案为空时使用作品 ID。
- 文件名删除 Windows 非法字符、控制字符和结尾空格或句点，基础名称最多 120 个字符。
- 后端不把完整视频写入项目目录或应用缓存。

**验收**

- GIVEN 有效解析令牌，WHEN 点击“下载视频”，THEN 浏览器按自身设置保存 MP4，通常为
  `C:\Users\<用户名>\Downloads`。
- GIVEN 大于内存缓冲区的视频，WHEN 下载，THEN 后端使用不超过 1 MiB 的应用层分块，不把完整文件加载进内存。
- GIVEN CDN 下载中断，WHEN 用户重试，THEN 可以复用未过期解析令牌重新下载。

### FR-006 选择保存位置

**行为**

- 在 Edge/Chrome 的 localhost 安全上下文中，由用户点击触发
  `showSaveFilePicker`。
- 使用与默认下载相同的建议文件名和 `.mp4` 类型。
- 前端将下载响应流写入用户选择的文件，不先创建完整 Blob。
- 用户取消文件选择属于正常取消，不显示错误。
- 浏览器不支持该接口时，提示后退回默认下载。

**验收**

- GIVEN 浏览器支持文件选择接口，WHEN 点击“选择保存位置”，THEN Windows 保存窗口出现且用户能选择目录和文件名。
- GIVEN 用户取消保存窗口，WHEN 返回页面，THEN 页面仍可继续操作且不显示失败。

### FR-007 主题

**行为**

- 页面右上角提供调色盘按钮。
- 可选主题为“明亮简洁”“深色抖音感”“冷静工具感”。
- 默认主题为“明亮简洁”。
- 选择写入浏览器 `localStorage`，下次启动恢复。
- 页面结构、字号层级和功能不随主题改变。

**验收**

- GIVEN 任意页面状态，WHEN 切换主题，THEN 颜色立即改变且输入和解析结果不丢失。
- GIVEN 已选择主题，WHEN 重新打开网页，THEN 恢复上次选择。

### FR-008 本地会话保护

**行为**

- 除最小健康检查外，API、封面和下载端点都要求有效的本次启动会话 Cookie。
- Host 必须是当前服务的 `127.0.0.1:<端口>` 或 `localhost:<端口>`。
- `POST /api/parse` 额外要求同源 Origin。
- 启动链接中的会话密钥只使用一次；服务器设置 Cookie 后使用 303 跳转到干净 URL。
- 禁用会记录完整请求查询参数的默认访问日志，应用日志不得记录会话密钥。

**验收**

- GIVEN 没有本地会话 Cookie，WHEN 外部网页或直接请求访问解析、封面或下载端点，
  THEN 返回 403。
- GIVEN Host 或 Origin 与当前本地实例不匹配，WHEN 请求受保护端点，THEN 返回 403。
- GIVEN 有效启动链接，WHEN 浏览器首次打开，THEN 建立会话并跳转到不含密钥的地址。

## 4. 页面设计

- 布局采用已确认的“单页聚焦式”：页头、居中的输入区、下方解析结果卡片。
- 桌面端结果卡片横向展示封面和元数据；窄屏时自然改为纵向。
- 主题按钮位于页头右上角。
- 使用系统字体，不依赖远程字体、图标或分析脚本。
- 所有按钮可通过键盘访问，拥有清晰焦点状态；正文和关键控件满足 WCAG AA 对比度目标。

## 5. 系统架构

### 组件

1. **Windows 启动器**
   - Tkinter 小型控制窗口。
   - 管理 FastAPI/uvicorn 后台线程、运行信息、浏览器打开和正常退出。

2. **本地 Web 应用**
   - FastAPI 提供页面、API、封面代理和视频流。
   - 原生 HTML、CSS 和 JavaScript，不引入 Node.js 构建链。

3. **输入与安全校验**
   - 提取分享链接。
   - 校验协议、域名、重定向和解析结果类型。

4. **抖音解析适配器**
   - 封装 f2 底层接口、游客标识、签名请求和响应映射。
   - 对上层只暴露稳定的应用数据结构，方便抖音规则变化时单独替换。

5. **内存解析仓库**
   - 以随机令牌保存解析结果和候选媒体地址。
   - 10 分钟 TTL、20 条上限、无持久化。

6. **媒体代理**
   - 校验媒体主机后流式代理封面和 MP4。
   - 生成安全文件名和下载响应头。

### 依赖方向

```text
浏览器页面
  → FastAPI 路由
    → 输入校验
    → 抖音解析适配器 → f2 → 抖音公开 Web 接口
    → 内存解析仓库
    → 媒体代理 → 受信任抖音 CDN

Windows 启动器 → FastAPI 生命周期
```

前端不直接依赖 f2 或抖音响应结构；FastAPI 路由不直接操作 f2 内部模型。

## 6. API 与错误契约

### `GET /api/health`

返回最小应用标识、状态和当前实例 ID，用于控制窗口与重复启动检测；不返回会话密钥、
媒体信息或解析状态。

### `POST /api/parse`

请求：

```json
{"share_text": "抖音分享文案或链接"}
```

成功响应：

```json
{
  "parse_token": "随机令牌",
  "video": {
    "aweme_id": "7429378937383308594",
    "author": "钟哥！！",
    "description": "#王者荣耀 #王者荣耀热门",
    "duration_ms": 15279,
    "cover_url": "/api/cover/随机令牌"
  }
}
```

### `GET /api/cover/{parse_token}`

仅为有效、未过期的解析记录代理封面。

### `GET /api/download/{parse_token}`

仅为有效、未过期的解析记录流式代理 MP4。

### 标准错误

```json
{
  "error": {
    "code": "INVALID_INPUT",
    "message": "没有识别到抖音链接，请粘贴完整分享文案。"
  }
}
```

| HTTP | 错误码 | 用户行为 |
| --- | --- | --- |
| 400 | `INVALID_INPUT` | 修正输入 |
| 400 | `UNSUPPORTED_URL` | 使用抖音公开视频链接 |
| 404 | `VIDEO_NOT_FOUND` | 检查作品是否存在 |
| 410 | `PARSE_EXPIRED` | 重新解析 |
| 422 | `UNSUPPORTED_CONTENT` | 当前版本不支持该内容类型 |
| 502 | `UPSTREAM_BLOCKED` | 稍后重试或更新解析适配器 |
| 502 | `DOWNLOAD_FAILED` | 在令牌有效期内重试 |
| 504 | `UPSTREAM_TIMEOUT` | 稍后重试 |

## 7. 超时、重试与资源控制

- 解析单次请求超时 20 秒。
- 仅对连接错误、超时和上游 5xx 自动重试一次；输入错误、作品不存在和不支持内容不重试。
- 重试采用短随机退避，解析总等待上限 45 秒。
- 页面持续显示当前状态，不使用无限转圈。
- 视频下载使用流式响应；客户端断开后立即关闭上游响应。
- 同一页面同一时刻最多一个解析请求；MVP 不额外构建任务队列。

## 8. 安全与隐私

- 服务只能绑定 `127.0.0.1`，不绑定 `0.0.0.0`。
- API 只允许已建立本次启动会话的同源浏览器访问，不启用开放 CORS。
- 页面输入 URL 只允许 FR-002 中列出的 HTTP(S) 主机；重定向逐跳校验，禁止访问
  localhost、私有 IP、文件协议和非受信任目标。
- 媒体代理只连接解析响应中的 HTTPS 地址，并限制为维护清单中的抖音 CDN 后缀；地址在请求时再次校验。
- 不读取或保存用户浏览器 Cookie、抖音账号、下载历史或视频内容。
- 游客标识只保存在应用内存和对应请求中，不写日志。
- 日志只记录时间、操作类型、匿名错误码、耗时和字节数；不记录完整分享文本、游客令牌、解析令牌、查询参数或媒体 URL。
- 日志存放于 `%LOCALAPPDATA%\DouyinLocalDownloader\logs`，每个文件不超过 1 MiB，最多保留 5 个文件。
- 工具仅用于用户拥有权利或已获授权的公开内容，不绕过平台访问控制。

## 9. 非功能要求

- 支持 Windows 10/11 x64。
- 支持当前稳定版 Microsoft Edge 和 Google Chrome。
- 正常网络下解析目标为 15 秒内完成，单次超时为 20 秒。
- 启动后 5 秒内显示控制窗口；本地服务就绪后再打开网页。
- 下载过程不得把完整视频加载到 Python 或浏览器 Blob 内存。
- 打包后的程序不要求用户预装 Python、Node.js 或 f2。
- 解析适配器与应用接口隔离，抖音规则变化时无需重写页面、启动器或下载逻辑。

## 10. 测试策略

### 单元测试

- 分享文案链接提取、输入长度和域名校验。
- 重定向逐跳校验和私有地址拒绝。
- Windows 文件名清理和长度限制。
- 解析响应映射、内容类型判断和错误映射。
- TTL、容量淘汰和过期令牌。
- CDN 主机允许清单。

### API 集成测试

- 使用确定性 f2 替身验证解析成功、上游失败、超时和重试。
- 使用本地流式媒体替身验证响应头、分块传输、客户端中断和上游关闭。
- 验证非同源请求不获得开放 CORS 权限。

### 浏览器 E2E

- 粘贴、解析、预览、默认下载、解析其他视频。
- 三主题切换和偏好恢复。
- 重复点击只产生一个活动请求。
- 文件选择接口支持、取消和不支持时的退回路径。
- 桌面和窄屏布局、键盘操作及焦点可见性。

### 真实受控验证

- 使用作品 `7429378937383308594` 进行显式运行的真实集成测试，不放入默认离线测试套件。
- 核对作品 ID、作者、文案、时长、MP4 类型、文件结构和可播放性。
- 首选比对已验证哈希；哈希变化时进行人工无水印抽检。
- 在打包后的 EXE 上完成双击启动、重复启动、重新打开网页、选择保存路径和安全退出。

## 11. 打包与目录

- 使用 PyInstaller 生成 Windows x64 可执行程序。
- 使用 `--windowed`，由 Tkinter 控制窗口承载可见生命周期，不显示命令行窗口。
- 静态网页、应用图标、f2 必需资源和配置随应用打包。
- 运行时可写内容只放入 `%LOCALAPPDATA%\DouyinLocalDownloader`。
- 项目目录和安装目录不写入下载文件、媒体缓存或运行日志。

## 12. 已知风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 抖音接口或签名规则变化 | 解析暂时不可用 | 独立解析适配器、明确错误码、固定验证样本、升级 f2 或替换适配器 |
| CDN 地址短期过期 | 下载失败 | 10 分钟令牌、过期提示、允许重新解析 |
| 游客访问策略变化 | 未来可能要求更新获取方式 | 不依赖用户 Cookie；失败时停止并提示，不自动读取账号信息 |
| 浏览器不支持文件选择接口 | 无法直接选路径 | 退回标准下载，并提示通过浏览器设置选择下载位置 |
